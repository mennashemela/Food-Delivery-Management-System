# Food-Delivery-Management-System
Food Delivery Management System

An object-oriented food delivery management system built in C++, focused on clean class design using inheritance, polymorphism, and dynamic data structures.

Overview

This project models the core entities of a food delivery platform — users, drivers, and orders — using object-oriented design principles rather than a flat, procedural structure.

Design
User hierarchy
Abstract User base class defining shared behavior/interface
Customer and DeliveryDriver subclasses built via inheritance
Polymorphism used so different user types can be handled through a common interface
Order management
Order class built on a dynamic array with automatic resizing, avoiding fixed-capacity limitations as orders grow
Tools

C++ · Object-Oriented Programming · Inheritance · Polymorphism · Dynamic Arrays
